Assignment 1

User Authentication using Biometric Features

The objective of this assignment is to let you gain some hands-on experience in the performance evaluation of a typical biometric system. You are provided with a data file that has biometric feature sets from each of the 100 users. Each user has provided 10 image samples: 5 during enrollment and 5 6 months after enrollment. The feature vectors from each of these 1000 image samples are stored in the data file. The system has acquired 144 features from each of the biometric images and generated a representative feature vector.

You have to use the first five image samples as training features and the remaining five as the test set to report test results.

The following performance curves/scores on the test data using
(i) Euclidean distance and 
(ii) cosine similarity as the matching distance are to be computed.
A. Genuine Distribution
B. Imposter Distribution
C. FAR Plot
D. FRR Plot
E. Receiver Operating Characteristics
F. Equal Error Rate and Decidability Index

Which matching distance criteria, in your opinion, perform the best?
